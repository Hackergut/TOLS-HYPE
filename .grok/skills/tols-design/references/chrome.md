# TOLS chrome — Solana accents

Canvas stays dark grey. Accents are Solana violet + mint.

| Role | HEX | Token |
|---|---|---|
| Background | `#0d0d10` | `--background` `--bg-0` |
| Card | `#16171b` | `--card` `--bg-1` |
| Sidebar | `#09090c` | `--sidebar` |
| Primary / CTA | `#904BF9` | `--primary` `--cta` |
| Primary hover | `#A665F5` | `--primary-bright` |
| Win / Bet / fair | `#00FFBD` | `--lime` `--win` `--success` |
| Mint hover | `#34EDCD` | `--lime-400` |
| VIP | `#EA2FD4` | `--vip` |
| VIP dark | `#9628A1` | `--vip-hover` |
| Loss / error | `#d55753` / `#e1514e` | `--loss` `--destructive` |
| Focus ring | `#904BF9` | `--ring` |

`--grad-solana`: `#904BF9 → #00FFBD` (Deposit / Claim)  
`--grad-solana-vip`: `#9628A1 → #EA2FD4`

Ink: mint fill → `#0d0d10`. Violet CTA → white.

Do not use `#000` as page background.
